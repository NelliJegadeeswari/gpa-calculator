# GPA Calculator Web App

Simple web application to calculate GPA for students.  
Built with HTML, CSS, and JavaScript.  
Very useful for calculating semester GPA.

## ✅ Features
- Add multiple subjects dynamically  
- Calculate GPA instantly  
- Simple, beginner-friendly interface  

## 🚀 How to Use
1. Open `index.html` in browser  
2. Add subject name, credit hours, and grade  
3. Click "Calculate GPA"  
4. See GPA displayed on screen

## 📂 Tech Stack
- HTML  
- CSS  
- JavaScript
